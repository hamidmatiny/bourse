# 0002 — A2A v1.0, a2a-sdk 1.2.3, JSON-RPC binding first

## Context
Agents from different vendors must interoperate through one protocol. A2A v1.0 defines Agent Cards,
tasks and transport bindings (JSON-RPC, gRPC, HTTP+JSON).

## Decision
- Target A2A spec 1.0 (`A2A_SPEC_VERSION = "1.0"` in `bourse.cli`).
- Pin `a2a-sdk==1.2.3`.
- Implement the JSON-RPC binding first; other bindings only if a phase needs them (new ADR).
- Agent Cards are served at `/.well-known/agent-card.json`. Card signing (JCS + JWS, pinned vendor
  keys) is Phase 1.

## Consequences
- SDK upgrades are explicit pin changes with a test run.
- `bourse doctor` prints the installed a2a-sdk version so drift is visible.

## Status
Accepted (Phase 0). Card crypto: Phase 1.
