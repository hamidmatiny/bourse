# 0003 — MCP 2026-07-28 via mcp 2.x; in-house LangChain tool adapter

## Context
Agents use MCP for their own tools. The `mcp` Python SDK 2.x implements protocol revision
2026-07-28. `langchain-mcp-adapters` does not support mcp 2.x. The MCP Tasks extension is not
available in the Python SDK.

## Decision
- Use protocol revision 2026-07-28 (`MCP_SPEC_VERSION` in `bourse.cli`) via `mcp` 2.x, exact pin
  (2.3.0 at Phase 0).
- Write a thin in-house adapter from MCP tools to LangChain tools (Phase 2) instead of depending on
  `langchain-mcp-adapters`.
- Do not use the MCP Tasks extension.

## Consequences
- We own a small adapter and its tests.
- Long-running tool work is tracked by BOURSE (A2A tasks), not MCP Tasks.

## Status
Accepted (Phase 0). Adapter: Phase 2.
